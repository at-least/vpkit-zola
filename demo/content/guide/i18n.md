# Internationalization

A site in more than one language is a Zola site with [languages](https://www.getzola.org/documentation/content/multilingual/). The theme adds VitePress's language menu and settings per language.

## Languages and Locales

Each language is Zola's, in `config.toml`, and an entry in `locales` under `[extra]`:

```toml
default_language = "en"

[languages.zh]
title = "我的文档"   # Zola: each language has its own title

[extra]
lang_menu_label = "Change language"   # the default

[[extra.locales]]
code = "en"          # the language's code in Zola
label = "English"
lang = "en-US"       # optional: the pages' and the links' lang (default: the code)

[[extra.locales]]
code = "zh"
label = "简体中文"
lang = "zh-Hans"
dir = "ltr"          # optional
lang_menu_label = "多语言"
nav = [{ text = "指南", link = "@/guide/introduction.zh.md" }]
outline_label = "页面导航"
```

An entry can give any of the theme's settings for its language: the navbar, the sidebar, the labels, the footer. It replaces the site's, a whole setting at a time, as a VitePress locale's `themeConfig` does: a locale's `nav` replaces the site's `nav`.

{% <vp_container type="warning" title="Each language's title"> %}
Zola gives a language without its own `title` under `[languages.<code>]` no title at all: its pages' navbar title and `<title>` would be empty.
{% </vp_container> %}

## Pages

A page in another language is the file with the language's code: `content/guide/introduction.zh.md` is `/zh/guide/introduction/`. Zola places it there only when its section is in that language too, `content/guide/_index.zh.md` (with `render = false` if the section has no page of its own); without it, the page has no section and no place in the site.

## The Language Menu

With two locales or more, the navbar has VitePress's language menu: a flyout in the bar (in the extra menu when the bar is full, opening in place on a phone's nav screen), labeled with the current language, linking the page to the same path in each other language. A link keeps the page's hash and query, as they change. The navbar's title links to the language's home page.

## Search

VitePress keeps a search index per language, and so does the theme: each language has its own index page, `content/vp-search.<code>.md`, the same as `content/vp-search.md`. See [Search](@/reference/search.md).

## Translating the Texts

The texts VitePress lets a locale translate are settings here too, so a locale can give its own: every label of the navbar, the sidebar and the doc footer, `skip_to_content_label`, the search box's texts, and the markdown's:

```toml
[[extra.locales]]
code = "zh"
# …
search_button_text = "搜索文档"
search_box = { no_results_text = "无法找到相关结果", navigate_text = "切换", select_text = "选择", close_text = "关闭" }
container_labels = { tip = "提示", warning = "警告", info = "信息", danger = "危险", details = "详细信息" }
code_copy_button = { tooltip_text = "复制代码", copied_text = "已复制" }
```

The [settings reference](@/reference/settings.md) lists them with their defaults.

## Heading Anchors

Zola makes a heading's id as `[slugify] anchors` says, which by default transliterates CJK headings (`快速开始` becomes `kuai-su-kai-shi`) where VitePress keeps the characters.
