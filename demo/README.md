# vpkit-zola's documentation

The theme's documentation, as a site built with the theme: the guide (what it is, getting started, markdown, languages, coming from VitePress) and the reference (settings, front matter, navbar, sidebar, home page, doc footer, search). The pages are under `content/`.

```sh
cd demo && zola serve
```

`themes/vpkit-zola` links to this repository, so the site shows the theme as it is here.
