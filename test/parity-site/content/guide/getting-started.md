# Getting Started

## Try It Online

You can try VitePress directly in your browser on StackBlitz.

## Installation

### Prerequisites

Node.js version 20 or higher.

### Setup Wizard

VitePress ships with a command line setup wizard.

## File Structure

If you are building a standalone VitePress site, you can scaffold the site in your current directory.

### The Config File

The config file allows you to customize various aspects of your VitePress site.

### Source Files

Markdown files outside the `.vitepress` directory are considered source files.
